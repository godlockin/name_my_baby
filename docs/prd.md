**版本：** v1.0

**状态：** 草稿

## 1. 产品概述

### 1.1 产品定位
一款面向中国父母的 AI 起名工具，通过多专家 Agent 团队协作，为新生儿提供有文化内涵、寓意美好、无谐音问题的姓名方案。

### 1.2 目标用户
- 新手父母（85 后/90 后/95 后）
- 有起名需求但缺乏相关知识背景
- 重视名字的文化内涵和寓意
- 可能需要中英文双语名字

### 1.3 核心价值
- **专业性**：多领域专家 Agent 协作（古诗词、历史、玄学、语言学等）
- **全面性**：谐音检查、五行分析、典故出处、英文名匹配
- **个性化**：根据家庭信息定制，支持多子女名字关联设计
- **高效性**：分层输出，快速浏览 + 深度分析

## 2. 功能需求

### 2.1 信息采集模块

#### 2.1.1 必填信息
| 字段 | 类型 | 说明 |
|------|------|------|
| 父亲姓名 | 文本 | |
| 母亲姓名 | 文本 | |
| 子女数量 | 数字 | 1-4 |
| 每个子女的性别 | 选项 | 男/女 |
| 每个子女的出生时间 | 日期时间 | 精确到分钟 |

#### 2.1.2 选填信息
| 字段 | 类型 | 说明 |
|------|------|------|
| 字辈要求 | 文本 | 如中间字为"晓" |
| 风格偏好 | 文本（填空） | 用户自由描述 |
| 特殊要求 | 文本 | 其他需求 |
| 手机号 | 文本 | 可选，用于用户识别 |

#### 2.1.3 智能分析
- 分析选填内容，动态调整 Agent 权重
- 例如：提到"希望出自诗词" → 提高古诗词专家权重

### 2.2 Agent 团队模块

#### 2.2.1 Agent 组成

| Agent | 职责 | 输出 |
|-------|------|------|
| **八字分析师** | 五行喜忌分析 | 八字、五行强弱、喜用神建议 |
| **谐音梗专家** | 全维度谐音检查 | 问题谐音列表、风险等级 |
| **古诗词专家** | 典籍出处考据 | 出处、原句、解释（分级标注） |
| **历史学家** | 历史典故分析 | 典故来源、寓意（分级标注） |
| **英文语言学专家** | 英文名推荐 | 英文名列表、寓意关联说明 |
| **欧洲历史专家** | 英文名典故来源 | 女神/神祇背景故事 |
| **汇总员** | 整合生成方案 | 完整名字方案 |

#### 2.2.2 协作流程（C 混合式）

```
用户输入
   ↓
【八字分析师】确定五行喜忌、用字范围（软性建议）
   ↓
【谐音梗专家】过滤有问题的谐音
   ↓
并行分发：
  ├→【古诗词专家】从典籍中找寓意好的字
  ├→【历史学家】考据字的历史典故
  ├→【英文语言学专家】推荐匹配的英文名
  └→【欧洲历史专家】英文名典故来源
   ↓
【汇总员】整合所有输入，生成多个完整方案
```

#### 2.2.3 分级标注规范
| 等级 | 标识 | 说明 |
|------|------|------|
| ✅ 确凿出处 | 绿色标记 | 确实可考据的出处 |
| ⚠️ 类似意境 | 黄色标记 | 化用意境，非直接引用 |
| 💡 美好寓意 | 灰色标记 | 纯粹寓意解释，无出处 |

### 2.3 输出展示模块

#### 2.3.1 分层设计

**Layer 1 - 简要版**
- 展示 3-5 个名字方案
- 每个名字包含：中文名、英文名（如有）、一句话寓意
- 适合快速浏览

**Layer 2 - 详细版**
- 用户点击后展开
- 包含完整分析链：
  - 五行分析
  - 谐音检查结果
  - 诗词出处（如有）
  - 历史典故（如有）
  - 英文名来源（如有）
  - 多子女名字关联（如有）

#### 2.3.2 支持的场景
- ✅ 单个小孩
- ✅ 同性双胞胎/多胞胎
- ✅ 异性双胞胎/多胞胎
- ✅ 多个非双胞胎子女（如兄妹、姐弟等）

### 2.4 反馈迭代模块

#### 2.4.1 👍/👎 简单反馈
- 每个名字可点 👍 或 👎
- 点 👎 后可选原因：
  - 不喜欢谐音
  - 不喜欢寓意
  - 五行不合
  - 其他

#### 2.4.2 📌 Pin 功能
- 用户可以 Pin 住某个名字（如"喜欢儿子的名字"）
- 点击"重新生成"时，保持 Pin 住的，只改其他
- 自动保持多子女名字的关联性

#### 2.4.3 📊 对比功能
- 用户可收藏多个名字
- 生成对比表，维度包括：
  - 寓意
  - 谐音风险
  - 五行匹配
  - 出处等级

### 2.6 支付与邀请码模块

#### 2.6.1 免费版权益
- 生成 1-2 个基础方案
- 基础谐音检查
- 基础寓意解释
- **不含**英文名、详细分析、收藏/对比功能

#### 2.6.2 付费版权益
- 解锁 5-8 个完整方案
- 完整谐音检查（含方言、中英文）
- 详细分析（诗词出处、历史典故、五行分析）
- 英文名推荐 + 典故
- 收藏/对比功能
- Pin + 定向重新生成
- 多子女名字关联优化

#### 2.6.3 支付套餐
| 套餐 | 价格 | 权益 |
|------|------|------|
| 次卡 | 19.9 元 | 1 次完整生成 + 无限迭代 |
| 无限卡 | 39.9 元 | 7 天内无限生成 |
| 家庭卡 | 59.9 元 | 30 天内为多个孩子起名 |

#### 2.6.4 邀请码系统
- 用户可生成邀请码分享给朋友
- 邀请码可解锁：
  - 额外 1 次免费生成
  - 或解锁英文名功能
- 被邀请人付费，邀请人获得返利（可选）

#### 2.6.5 支付方式
- 微信支付
- 支付宝支付

### 2.7 视觉设计模块

#### 2.7.1 色彩规范
| 颜色 | 色值 | 用途 |
|------|------|------|
| 朱砂红 | `#C44536` | 按钮、强调元素 |
| 米白色 | `#F8F4E8` | 背景色 |
| 墨色 | `#2C2C2C` | 正文文字 |
| 淡金 | `#D4AF37` | 高亮、付费元素 |

#### 2.7.2 字体规范
| 场景 | 字体 | 说明 |
|------|------|------|
| 标题 | 思源宋体 | 文化感 |
| 正文 | 思源黑体 | 易读性 |

#### 2.7.3 视觉元素
- 简约中式纹样（云纹、回纹）作为装饰
- 印章风格的 logo/图标
- 留白 + 部分场景竖排文字

#### 2.7.4 信息架构（IA）与页面结构
**核心原则：**少填快跑、先给结果后给证据、可随时迭代、付费权益不打断关键路径。

**页面清单（Web / 小程序一致）：**
- 首页/引导：价值说明 + 案例预览 + 开始起名 CTA
- 信息采集（表单）：必填优先，选填折叠；支持多子女/多胎配置
- 生成中：进度提示 + 分阶段展示（八字/谐音/典故检索/汇总）+ 超时兜底
- 结果列表（Layer 1）：3-8 个方案卡片（免费为 1-2 个基础卡片）
- 方案详情（Layer 2）：抽屉/详情页展开完整分析链
- 收藏与对比：对比表（寓意/谐音风险/五行匹配/出处等级）
- 迭代再生成：支持 Pin、反馈原因选择、保留已选项重跑
- 支付与权益：购买页、支付结果页、权益说明
- 邀请码：生成/输入邀请码、规则说明
- 历史记录：按 Device ID + 时间戳列出会话与结果（可选）

#### 2.7.5 核心流程与交互
**表单采集：**
- 分步式：Step 1 家庭信息（父母姓名）→ Step 2 子女信息（人数、每位性别/出生时间）→ Step 3 偏好（字辈/风格/特殊要求）→ 提交
- 动态表单：子女数量变更后自动增减子女子表单；多胎提供“批量复制出生时间/偏好”快捷操作
- 校验策略：输入中轻提示、提交时强校验；错误定位到字段并给出可执行建议

**生成中：**
- 15s 目标：超过 8s 显示“继续生成中”并提供“先看基础结果”兜底
- 失败兜底：单个 Agent 超时 → 以降级输出继续（例如缺少英文名来源，但仍给出中文方案）

**结果与迭代：**
- Layer 1 默认只露出：中文名 + 英文名（如有）+ 一句话寓意 + 谐音风险标签 + 出处等级标签（如有）
- Layer 2 展开后按固定顺序：寓意 → 谐音检查 → 五行分析 → 出处/典故 → 英文名来源 → 多子女关联说明
- 反馈：👍/👎 一键；👎 触发原因选择（谐音/寓意/五行/其他），用于下一轮权重调整
- Pin：Pin 的方案在再生成时保持不变；其余方案替换并保持“同一风格/同一主题”一致性

#### 2.7.6 组件与信息呈现规范
**基础组件：**
- 按钮：主按钮（朱砂红）、次按钮（描边）、幽灵按钮（文字）
- 表单：输入框/选择器/日期时间选择器；子女子表单用 Card 分组
- 卡片：名字方案卡（可点击展开）、收藏卡、支付卡
- 抽屉/折叠：用于 Layer 2 详情展开；移动端优先抽屉

**标签体系（统一位置：卡片右上角或标题旁）：**
- 出处等级：✅ 确凿出处 / ⚠️ 类似意境 / 💡 美好寓意
- 谐音风险：低/中/高（用中性措辞，不使用夸张警告语）
- 权益：付费解锁（淡金强调，仅在用户触达该能力时出现）

**内容排版：**
- 每个分析块遵循：结论一句话（可读）→ 证据/列表（可查）→ 说明（可选）
- 典故/诗词引用：原文与解释分层，默认收起原文；提供“复制引用”能力（可选）

#### 2.7.7 文案与语气
- 基调：温和、审慎、重文化与可解释性
- 避免：绝对化承诺（如“包好命”）、恐吓式话术、封建迷信夸张表达
- 建议：八字/五行结论以“软性建议”呈现，并强调“仅供参考”

#### 2.7.8 可用性与无障碍（A11y）
- 对比度：正文与背景满足可读性，淡金仅用于强调不用于长文本
- 字号：正文 14-16px（或等效），标题层级清晰
- 触控：可点击区域 ≥ 44px；卡片整块可点
- 动效：默认 200-300ms，支持减少动效偏好（如系统设置）

#### 2.7.9 多端适配规范
- 响应式：移动端单列；平板/桌面双列展示卡片与详情（可选）
- 安全区：小程序/刘海屏适配顶部与底部安全区
- 输入体验：日期时间选择器在小程序使用原生控件优先；Web 使用一致的交互模式

## 3. 非功能需求

### 3.1 性能要求
- 首屏加载时间 < 2s
- 名字生成时间 < 15s（含多 Agent 协作）

### 3.2 安全要求
- 用户数据加密存储
- 支付接口安全校验
- 防止刷单/恶意调用

### 3.3 可用性要求
- 支持微信小程序和 Web 双端
- 关键路径有兜底方案（如 Agent 超时）
